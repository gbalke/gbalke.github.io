# Personal website

Greg Balke's personal site, originally built with [Bolt](https://bolt.new). Vite + React + TypeScript + Tailwind CSS.

## Development

```sh
npm install
npm run dev      # local dev server
npm run build    # static build to dist/
```

The build output in `dist/` is a fully static site and can be hosted on any static host (Netlify, GitHub Pages, Cloudflare Pages, etc.).
